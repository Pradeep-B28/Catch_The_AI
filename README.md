# Catch the AI by Wrench Wise

Catch the AI is a fast-paced web game where players review realistic code snippets generated by AI coding tools and spot the subtle bug in each snippet within 30 seconds.

Live Link: https://catch-the-ai.vercel.app/

---

## How to Play in 3 Steps

1. **Read what the code should do:** Review the task prompt at the top of the card.
2. **Tap the line with the mistake:** Inspect the code and select the line containing the bug.
3. **See what AI got wrong:** Review the fix diff, observe the "Run it" execution console, and learn the concept behind the mistake.

## How to Run Locally

### Requirements
- Node.js v18 or higher (tested with v24.18.0)
- Any modern web browser (Chrome, Edge, Safari, Firefox)

### Start Local Web Server
Clone or open the project folder in your terminal, then start an HTTP server:

```bash
# Using Python
python -m http.server 8000

# Or using Node.js npx
npx serve -l 8000
```

Open your browser at `http://localhost:8000/`.

### Run Automated Content Check
To verify that all 20 code snippets produce real errors in Node and that all fixes pass:

```bash
node tools/verify-content.mjs
```

### Run Browser Self-Test Suite
To run the browser engine test suite covering all checks a through n:
Open `http://localhost:8000/?test=1` in your browser.

## How It Works

1. **The Event Bus:** All UI screens, sound effects, analytics, and game logic communicate through a central, decoupled event bus (`events.js`). No screen directly manipulates another screen's state.
2. **High-Precision Timer:** The countdown timer calculates active elapsed time using differences between `performance.now()` timestamps rather than relying on `setInterval` ticks. It pauses automatically when the tab is hidden.
3. **Canvas Auto-Fit:** The monospace font size dynamically scales between 11px and 16px using canvas `measureText` calculations, ensuring the longest line fits the code card without horizontal scrolling or awkward line breaks.
4. **Self-Contained Challenge Links:** Challenge links carry snippet IDs and target scores directly in URL query parameters (`?set=b01.b02...&beat=6`). The client parses, validates, and runs the exact set with zero server dependency.
5. **Content Verification Harness:** Every challenge is backed by an automated runner (`tools/verify-content.mjs`) that executes both the buggy AI code and the corrected fix in Node to prove every bug is legitimate.
